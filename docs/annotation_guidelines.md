# Annotation Guidelines

## Canonical objects
DOOR, FRIDGE, BOTTLE, GLASS, CUP, DRAWER

## Canonical actions
OPENS, PICKS UP, PUT DOWN, POUR IN, WALKS, WASHING, COOKING

## Temporal rule
Start = first frame where the action is visibly occurring.
End = last frame where the action is visibly occurring.

## Object rule
Attach the object directly involved in the action. Do not label every visible object.

## PICK UP
Use when an object transitions from a resting/placed state into the person's hand.

## PUT DOWN
Use when an object transitions from being held to a resting/placed state.

## OPENS
Use when a door, refrigerator, or drawer is actively moved toward an open state.

## POUR IN
Use when liquid is visibly transferred into a receiving container.

## WALKS
Use only for visible walking movement; do not map unrelated transitions such as sitting/standing into WALKS.

## WASHING
Use for washing/rinsing/cleaning/wiping activity when it is the dominant interaction.

## COOKING
Use for cooking/manipulating food with cooking intent, including source-dataset verbs such as cook, fry, boil, heat, or stir-fry.

## Ambiguity
Do not guess. Route uncertain action/object/time boundaries to human review.
